# 哈基米 · 背屏幸存者

Canvas 2D / TypeScript / Vite 浏览器原型，逻辑画幅 904 × 572。角色支持透明 PNG 素材，图标和战斗特效由 Canvas 绘制；能力详情使用可滚动的 HTML 面板。

角色图片位于 `public/assets/characters/`：`hakimi.png`（玩家）、`maodie.png`（精英）、`dagoujiao.png`（普通敌人），已全部接入用户提供的抠图透明 PNG。加载失败或图片不透明时自动保留原程序角色，避免把白底或棋盘格画进战场。图片只加载一次，自动适配透明留白、缓存尺寸与受击闪白，沿用原移动动画及碰撞数值。生成提示词见该目录 README。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 生成可部署的 `dist/`，`npm test` 运行机制和长局测试。也可使用 pnpm。

浏览器交互测试：先启动开发服务器，再执行 `npm run test:browser`。默认访问 `http://localhost:5174`，可通过 `GAME_URL` 修改；测试使用本机 Google Chrome，截图输出至 `artifacts/`。

## 游玩

- 电脑：WASD 或方向键移动，自动攻击；点击菜单选择升级。Esc 暂停／继续。
- 手机：通过 **HTTPS** 访问，点击开始并允许方向传感器权限。以开始时握姿为中立点，倾斜移动。无触摸摇杆。
- 暂停菜单可校准、切换声音；每次继续或选完升级会重新校准。切后台、窗口失焦自动暂停。
- 904×572 等比适配，左侧两镜头遮挡只影响可见性，不影响碰撞。HUD 和菜单均位于右侧安全区。
- 击杀大狗叫拾取小米升级；第 1–9 分钟出现精英耄耋，掉落宝箱。8 级能力 + 已拥有对应被动即可由宝箱进化。存活 10 分钟获胜。
- 本地保存最佳生存时间和静音设置，无中途存档或局外成长。

## 能力与被动

每局最多四种能力，初始拥有哈气；每种能力上限八级。被动数量不限，点击能力栏暂停并查看全部能力、被动、当前效果与配方，关闭或按 Esc 继续。

| 能力 | 进化被动 | 进化结果 |
| --- | --- | --- |
| 哈气 | 冷却缩减 | 哈气永动机 |
| 老吴光环 | 生命恢复 | 老吴结界 |
| 基米挠 | 心心容器 | 超级基米挠 |
| 小白手套 | 子弹数量 | 小白连环拍：原落点二连拍 |
| 口香糖 | 持续时间 | 永恒口香糖：永久环绕 |
| 大运 | 攻击力 | 大运车队：基础三车连续驶入 |

大运以包含摄像头区域的完整画幅为边界，从四边随机驶入，沿召唤时锁定的角色位置直线行驶。车辆保持世界坐标路径，每车对每敌人伤害一次；四向图形的车头随方向转动，文字保持正向。

攻击范围（五级）：每级 +10%，影响声波射程、光环半径、挥爪范围、落爪半径、糖块大小及环绕半径、卡车体积与碰撞范围；画面和伤害判定同步放大。

新增被动：攻击力、移动速度、经验、持续时间、子弹速度每级 +10%，吸取范围每级 +20%（均五级）；子弹数量每级 +1（两级）。复活不可升级，每局只可获得一次，消耗后半血复活并无敌三秒。原冷却缩减、生命恢复、心心容器保留原数值与五级上限。

数量作用于哈气、基米挠、落爪和糖块，光环与大运除外。持续时间作用于普通糖块存在时间和卡车寿命；子弹速度作用于糖块转速和卡车车速。

## 结构与数值

`src/config.ts`：分辨率、镜头安全区、经验曲线、生成节奏、道具定义。
`src/game.ts`：固定步长模拟、空间网格、敌人对象池、攻击、经验与进化；攻击数值集中于 attacks 及对应能力方法。
`src/input.ts`：二维输入接口、方向传感器、键盘、校准与平滑。
`src/render.ts`：程序美术、世界、遮挡、HUD 和菜单。
`src/audio.ts`：Web Audio 合成音效。

开发模式提供 `window.__hakimi` 用于验证，生产构建不暴露此接口。游戏逻辑为无限地图，远离玩家的普通敌人回收；普通敌人上限 420，远处经验堆积后按空间合并并保留经验总量，宝箱不丢弃。

## 验证与限制

自动验证覆盖能力槽限制、全部被动共存、六种能力与进化、复活、属性加成、四方向卡车、对象池复用、暂停冻结、胜负结算和十分钟压力运行。Chrome 测试覆盖移动、升级、缩放点击、详情面板滚动和移动尺寸布局，并输出四方向车辆与新攻击截图。

八级能力与新增被动的数值尚未通过真实玩家长局校准。加速压力测试使用满构筑与持续补血，仅验证模拟稳定性，不代表普通玩法通关难度。

手机权限、横竖屏倾斜方向、设备帧率和小米真实背屏接入尚需真机验证。浏览器必须能提供 DeviceOrientation 数据；局域网 HTTP 通常无法提供手机传感器权限，需要为部署地址配置 HTTPS。

## GitHub Pages

推送到 `main` 分支后，GitHub Actions 会运行测试、构建游戏并发布 `dist/` 到 GitHub Pages。也可以在仓库的 **Actions → Deploy to GitHub Pages → Run workflow** 手动触发。

宝箱开启时按 70% / 25% / 5% 抽取 1 / 3 / 5 项奖励，只升级已拥有项目；每项重新计算资格，优先进化，可同箱连续升级后进化。无可升级项目时每项回复 30 生命。三档动画逐级增强，开箱暂停战斗，点击跳过至总览，再点击继续。屏外或左侧摄像头区域的宝箱显示方向箭头。全部能力、被动在升级、奖励和详情中使用绘制图标。

全屏动效：摄像头与战场同步抖动、变暗，并被全屏闪光覆盖。普通道具总掉率 1.75%（回血 0.875%、磁铁 0.5%、炸弹 0.375%），经验与精英宝箱掉落保持原规则。敌人生命使用更快的非线性成长；普通与精英速度随时间增加，三分钟后接触伤害开始增长，后期生成间隔缩短至 0.065 秒，敌人数量上限保留。
