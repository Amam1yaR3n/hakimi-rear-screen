# 哈基米 · 背屏幸存者

纯 Canvas 2D / TypeScript / Vite 浏览器原型，逻辑画幅 904 × 572。所有角色、按钮、图标、特效均由 Canvas 绘制，无图片素材依赖。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 生成可部署的 `dist/`，`npm test` 运行机制和长局测试。也可使用 pnpm。

浏览器交互测试：先启动开发服务器，再执行 `npm run test:browser`。默认访问 `http://localhost:5174`，可通过 `GAME_URL` 修改；测试使用本机 Google Chrome，截图输出至 `artifacts/`。

## 游玩

- 电脑：WASD 或方向键移动，自动攻击；点击菜单选择升级。Esc 暂停／继续。
- 手机：通过 **HTTPS** 访问，点击开始并允许方向传感器权限。以开始时握姿为中立点，倾斜移动。无触摸摇杆。
- 暂停菜单可校准、切换声音；每次继续或选完升级会重新校准。切后台、窗口失焦自动暂停。
- 904×572 等比适配，左侧两镜头遮挡只影响可见性，不影响碰撞。HUD 和菜单均位于右侧安全区。
- 击杀大狗叫拾取小米升级；第 1–9 分钟出现精英耄耋，掉落宝箱。5 级能力 + 1 级对应被动即可由宝箱进化。存活 10 分钟获胜。
- 本地保存最佳生存时间和静音设置，无中途存档或局外成长。

## 结构与数值

`src/config.ts`：分辨率、镜头安全区、经验曲线、生成节奏、道具定义。
`src/game.ts`：固定步长模拟、空间网格、敌人对象池、攻击、经验与进化；攻击数值集中于 tick 的三个能力分支。
`src/input.ts`：二维输入接口、方向传感器、键盘、校准与平滑。
`src/render.ts`：程序美术、世界、遮挡、HUD 和菜单。
`src/audio.ts`：Web Audio 合成音效。

开发模式提供 `window.__hakimi` 用于验证，生产构建不暴露此接口。游戏逻辑为无限地图，远离玩家的普通敌人回收；普通敌人上限 420，远处经验堆积后按空间合并并保留经验总量，宝箱不丢弃。

## 验证与限制

已通过 TypeScript 检查、生产构建、6 项模拟测试，覆盖成长上限、三套进化、冻结计时、9 次精英、胜负结算以及满构筑十分钟加速压力运行。Chrome 自动试玩验证键盘移动、升级暂停、半尺寸点击映射和暂停恢复，未发现浏览器异常。

首版数值以 2–3 分钟首次进化为设计目标，尚未通过真实玩家长局校准。加速压力测试使用满构筑与持续补血，仅验证模拟稳定性，不代表普通玩法通关难度。

手机权限、横竖屏倾斜方向、设备帧率和小米真实背屏接入尚需真机验证。浏览器必须能提供 DeviceOrientation 数据；局域网 HTTP 通常无法提供手机传感器权限，需要为部署地址配置 HTTPS。
